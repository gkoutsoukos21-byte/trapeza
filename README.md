# Τράπεζα Θεμάτων · Λύκειο

Εφαρμογή (PWA) για κινητά με τα θέματα της Τράπεζας Θεμάτων του ΙΕΠ για Μαθηματικά, Φυσική, Χημεία και Βιολογία (ΓΕΛ & ΕΠΑΛ).

## Ανέβασμα στο GitHub Pages (μία φορά, από υπολογιστή)

1. Μπείτε στο github.com → **New repository**. Όνομα π.χ. `trapeza`, επιλογή **Public** → **Create repository**.
2. Πατήστε **uploading an existing file**. Σύρετε **όλα τα αρχεία** από το zip (όχι τον εξωτερικό φάκελο) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, φάκελος **/(root)** → **Save**.
4. Σε 1–2 λεπτά η εφαρμογή είναι στο `https://ΟΝΟΜΑ-ΧΡΗΣΤΗ.github.io/trapeza/`.

## Για τους μαθητές

- Ανοίγουν το link (ή σκανάρουν το QR code).
- **Android/Chrome:** ⋮ → «Εγκατάσταση εφαρμογής» ή «Προσθήκη στην αρχική οθόνη».
- **iPhone/Safari:** Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».

## Ενημέρωση θεμάτων

Η εφαρμογή ελέγχει μόνη της τον κατάλογο του ΙΕΠ κάθε φορά που ανοίγει ένα μάθημα, άρα τα νέα θέματα εμφανίζονται αυτόματα.
Το `data.js` είναι εφεδρικό αντίγραφο του καταλόγου (21/11/2026), για την περίπτωση που ο server του ΙΕΠ δεν απαντά.

## Αρχεία

- `index.html`, `app.js`: η εφαρμογή
- `data.js`: κατάλογος θεμάτων (κωδικός, Θέμα 2/3/4, ενότητες)
- `manifest.webmanifest`, `sw.js`, ``: ό,τι χρειάζεται για να εγκαθίσταται στο κινητό

## Νέο φροντιστήριο (άλλη ταυτότητα)

1. Αλλάξτε το `config.js` (όνομα, σύνθημα, χρώματα, στοιχεία επικοινωνίας).
2. Αντικαταστήστε τα `logo-header.png`, `logo-header-sm.png` και τα εικονίδια `icon-*.png`.
3. Αλλάξτε `name` και `theme_color` στο `manifest.webmanifest`.
4. Ανεβάστε τα αρχεία σε νέο αποθετήριο και ενεργοποιήστε το GitHub Pages.

## Αναζήτηση με λέξη-κλειδί

Η αναζήτηση χρησιμοποιεί μόνο τις λέξεις-κλειδιά του Ι.Ε.Π. και τους τίτλους των ενοτήτων (όχι τις εκφωνήσεις).
- Ακριβής: ό,τι περιέχει τη λέξη ή φράση (χωρίς τόνους/κεφαλαία).
- Συναφής: ίδια έννοια με άλλες λέξεις, βάσει του λεξικού `concepts.js` (μπορείτε να προσθέσετε γραμμές).
- Συνδυαστική: και τα δύο σε χωριστές ομάδες.
